# Techima private feedback inbox

This repository must remain **PRIVATE**. It stores personal information submitted through the Techima website, including email addresses. Do not publish it or change its visibility.

Each submission is stored as a separate JSON file under `submissions/YYYY-MM/<uuid>.json`. The public website repository contains only the display name, message, random ID, and timestamp in `comments.json`.

Do not put tokens or other secrets in this repository. Access the email records only through GitHub while signed in with an account authorized for this private repository.
