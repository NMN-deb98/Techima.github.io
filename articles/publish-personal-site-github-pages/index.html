ساخت و انتشار سایت شخصی با GitHub Pages

GitHub Pages راهی ساده برای انتشار سایت‌های استاتیک است؛ یعنی سایت‌هایی که خروجی آن‌ها از فایل‌هایی مانند HTML، CSS، JavaScript و تصاویر تشکیل می‌شود. برای نمونه‌کار شخصی یا صفحه معرفی پروژه، این روش می‌تواند شروع مناسبی باشد.

GitHub Pages راهی ساده برای انتشار سایت‌های استاتیک است؛ یعنی سایت‌هایی که خروجی آن‌ها از فایل‌هایی مانند HTML، CSS، JavaScript و تصاویر تشکیل می‌شود. برای نمونه‌کار شخصی یا صفحه معرفی پروژه، این روش می‌تواند شروع مناسبی باشد.

۱. فایل‌های سایت را منظم کنید

در ساده‌ترین حالت، سایت به یک فایل index.html و فایل‌های CSS، JavaScript و تصاویر نیاز دارد. بهتر است از ابتدا ساختار پوشه‌ها را روشن نگه دارید تا نگهداری و پیدا کردن فایل‌ها آسان شود. سایت شخصی تکیما هم بر پایه همین ایده، یعنی سازمان‌دهی فایل‌های یک سایت استاتیک، ساخته شده است.

برای سایت چندصفحه‌ای می‌توانید هر بخش را در پوشه جداگانه قرار دهید؛ مثلاً about/index.html و articles/index.html. لینک‌های داخلی باید با ساختار واقعی مخزن سازگار باشند.

۲. منبع انتشار را تنظیم کنید

کد سایت را در مخزن GitHub قرار دهید و در Settings بخش Pages، منبع انتشار را مطابق ساختار پروژه انتخاب کنید. بسته به تنظیمات، سایت ممکن است از شاخه‌ای مانند main و پوشه ریشه یا از فرایند ساخت منتشر شود.

اگر سایت در آدرس پروژه‌ای منتشر می‌شود، معمولاً زیر مسیر نام مخزن قرار می‌گیرد. بنابراین مسیرهایی که با / شروع می‌شوند باید با دقت بررسی شوند؛ ممکن است به ریشه دامنه اشاره کنند، نه ریشه سایت پروژه.

۳. نسخه منتشرشده را جداگانه بررسی کنید

دیدن فایل در مخزن به این معنی نیست که نسخه زنده هم حتماً به‌روز شده است. پس از commit، وضعیت انتشار را بررسی کنید و سپس URL واقعی را در مرورگر باز کنید.

اگر تغییر دیده نمی‌شود، مطمئن شوید فایل را در شاخه و پوشه درست تغییر داده‌اید. سپس وضعیت Pages، خطاهای فرایند ساخت و کش مرورگر را بررسی کنید. بارگذاری مجدد سخت‌گیرانه کمک می‌کند کش را تشخیص دهید، اما جای بررسی وضعیت انتشار را نمی‌گیرد.

۴. پیش از انتشار، آزمون کوتاهی انجام دهید

  • بررسی لینک‌ها و مسیر فایل‌ها
  • بررسی نمایش در موبایل
  • بررسی عنوان و canonical هر صفحه
  • بررسی وضعیت آخرین انتشار
  • بررسی نبود اطلاعات محرمانه

۵. چه زمانی GitHub Pages کافی نیست؟

برای سایت معرفی، نمونه‌کار و وبلاگ استاتیک انتخاب خوبی است. اما قابلیت‌هایی مانند ورود امن کاربران، پایگاه داده پویا یا مدیریت محتوا از سمت سرور به سرویس‌ها و معماری جداگانه نیاز دارند. قبل از افزودن چنین قابلیت‌هایی، مدل امنیتی و نحوه ذخیره داده‌ها را طراحی کنید.
